# Cocklebur Server 0.2.17.2

**Release marker:** SERVER-0.2.17.2-HOST-CREDENTIAL-CLEANUP

This patch cleans up the Server Host credential model while retaining the 0.2.17.1 recovery fix and all 0.2.17 features.

## Host lifecycle

Cocklebur Server now uses exactly three concepts:

1. **Bootstrap Key** — configured only as `COCKLEBUR_BOOTSTRAP_KEY`; used through **Claim Host** (`/api/host/claim`) to claim an unclaimed Instance Host.
2. **Host Session** — the browser cookie used for normal Host access.
3. **Host Recovery Code** — generated by Cocklebur; restores Host access after browser cookies are lost and rotates after successful recovery.

Server mode requires `COCKLEBUR_BOOTSTRAP_KEY` to be explicitly configured. A missing key causes startup to fail with a clear configuration error instead of silently generating an unknown credential.

The break-glass command remains available:

```bash
python -m app.admin reset-host --yes
```

It backs up instance auth state, clears only the Host claim, and preserves projects and delegated instance grants. After reset, claim Host again with the configured Bootstrap Key.

## Retained features

- Existing 0.2.16 `.instance_auth.json` Host state and recovery codes remain compatible.
- Workspace Bundle export/import and preflight.
- Notes as a Card type.
- Idempotent Card creation and visible Saving state.
- New Project spacing fix.
- Update Center validation, backup, and staging foundation.
