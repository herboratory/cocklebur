# Changelog

## 0.2.15 — First Public Release

First public Cocklebur release.

### macOS Desktop
- Local-only, single-user desktop edition
- Native macOS application wrapper
- Portable project export / import

### Self-hosted Server
- Docker-based deployment
- Owner / Member / Viewer roles
- Invitation and recovery links
- Shared project activity history

### Core workspace
- Projects and dashboard
- Announcements
- To-do / Event Cards
- Checklists, tags and assignees
- Discussion channels and titled threads
- Project files
- Visibility and edit-access controls
- Portable project packs with structured and human-readable content
